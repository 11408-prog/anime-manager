# 二次元图片收藏管理器

一个功能丰富的桌面应用，专为二次元爱好者设计，用于管理和浏览你的图片收藏。支持标签分类、收藏、私密空间、相似图片查找、网络爬虫等功能。dist中有已经打包好的应用，以及用法，点击即可使用，且包含使用方法。

---

## ✨ 功能特性

- **图片管理**：添加、删除、编辑图片信息（分类、标签）。
- **批量操作**：支持多选删除、全选/取消全选。
- **智能标签**：标签自动补全，支持热门标签推荐。
- **多维度筛选**：按分类、收藏状态、标签关键词筛选图片。
- **相似图片查找**：基于感知哈希（pHash）计算相似度，快速找到内容相近的图片。
- **收藏夹**：将喜欢的图片标记为收藏，并可导出/导入收藏夹（ZIP包，包含图片和元数据）。
- **私密空间**：通过密码保护的独立空间，存放私人图片。首次进入需设置密码，之后需验证密码。
- **网络爬虫**：支持通用网页和B站专栏图片爬取，一键下载并自动导入图库。
- **标签云**：以词云形式直观展示热门标签。
- **随机漫游**：随机浏览图库中的图片。
- **今日推荐**：基于日期随机推荐一张图片。
- **主题切换**：支持浅色/深色两种主题，界面美观。
- **异步加载**：缩略图后台加载，数据库查询不卡顿。

## 🛠️ 技术栈

- Python 3.8+
- PyQt5 —— 图形界面框架
- SQLite —— 本地数据库
- Pillow —— 图像处理
- imagehash —— 感知哈希计算
- requests + BeautifulSoup4 —— 网络爬虫
- wordcloud + matplotlib —— 标签云生成
- qtawesome —— 图标库
